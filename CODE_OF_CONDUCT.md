# Code of conduct

omarchy-herd follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep discussion about the work, not the person. Harassment, insults, discrimination and personal attacks aren't welcome in issues, pull requests, discussions or anywhere else the project lives.

## Reporting

If someone's behavior bothers you, contact the maintainer, [@andidst](https://github.com/andidst). If it's happening in a thread, you can also use GitHub's **Report content** option on the comment. Reports are handled privately.

Maintainers may edit or remove comments, lock threads, and block people who don't follow this code, as described in the Contributor Covenant's enforcement guidelines.
